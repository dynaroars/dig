## Program documentation

Each C file has a header explaining its purpose, source evidence, expected
invariants at named trace locations, and arithmetic assumptions. Unverified
original attribution is stated explicitly. Equations are mathematical
specifications; expanded C assertions can overflow even for valid runs.
