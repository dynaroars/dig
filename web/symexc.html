DIG SymEx: Symbolic Execution for C

This page demonstrates symex_c, the symbolic execution engine used by DIG. It explores every path of a C program with z3, computing per-path symbolic states (path condition + variable values at each vtraceX point), checking vasserts and safety properties (division by zero, array bounds, overflow) with concrete counterexamples and witness traces, generating path-covering test inputs, and proving loop invariants and termination unboundedly via k-induction and ranking functions — user-given, lexicographic, or auto-synthesized (linear and multiphase) — plus non-termination proofs with concrete diverging inputs.
