How DIG Works

DIG analyzes execution traces collected from program runs or symbolic execution to infer numerical relationships among variables. Annotate locations in C code using vtraceX(...) calls.

Annotating Programs

Declare dummy functions like void vtrace1(int x, int y){} and place calls at loop heads or exit points to specify which variables to monitor.

Supported Invariants

Equalities: Polynomial relations like x*y - z == 0.
Inequalities: Octagonal bounds like -4 <= x - y <= 10.
Congruences: Modular properties like x == 0 (mod 4).
