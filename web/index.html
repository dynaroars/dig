DIG: Dynamic Invariant Generator

DIG infers program invariants — nonlinear/linear equalities, octagonal inequalities, congruences, and min/max-plus relations — from program code or execution traces, with Z3 symbolic verification and optional unbounded Lean 4 certification. [SymEx] [GitHub] [ROARS Lab]

This project is dedicated to the memory of Deepak Kapur (1950–2026), DIG's co-creator and mentor.
